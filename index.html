Slide 2 — Overview

Introduction to Uniform Cost Search

Definition: Uniform Cost Search (UCS) is an uninformed search algorithm that finds the least-cost path from a starting node to a goal node. It expands the node with the lowest cumulative path cost first.

How Does It Work?

  • Starts from the initial node with a cost of zero.
  • Explores the node with the lowest total cost.
  • Calculates the cost of reaching neighboring nodes.
  • Updates the path if a cheaper route is found.
  • Stops when the goal is selected from the Frontier.
Advantages
  • Finds optimal path when edge costs are non-negative.
  • Does not require heuristic information.
  • Handles different path costs effectively.
Disadvantages
  • Can consume a large amount of memory.
  • May explore many unnecessary nodes.
  • Can be slower than informed search algorithms.
Applications
  • GPS and route finding.
  • Network routing.
  • Pathfinding in Artificial Intelligence.

Main Search Algorithm ucs.py: lines 23-65 
def uniform_cost_search(s, goal):
    FRONTIER = [(0, s)]
    EXPLORED = set()
    COST = {s: 0}
    PARENT = {s: None}

    while FRONTIER:
        current_cost, u = ExtractMin(FRONTIER)
        if u == goal:
            return BuildPath(PARENT, u), COST[u]

        EXPLORED.add(u)

        for v, edge_cost in graph[u]:
            if v in EXPLORED:
                continue
            new_cost = COST[u] + edge_cost
            if v not in COST or new_cost < COST[v]:
                COST[v] = new_cost
                PARENT[v] = u
                UpdatePriorityQueue(FRONTIER, v, new_cost)

    return [], float('inf')

Slide 5 — Helper Functions

Helper Functions Deep Dive

1. ExtractMin(FRONTIER) Priority Queue 
def ExtractMin(FRONTIER):
    FRONTIER.sort()
    return FRONTIER.pop(0)
  • FRONTIER.sort() sorts nodes according to their costs.
  • pop(0) removes and returns the node with lowest cost.
  • Ensures that UCS always selects the cheapest available node.
2. BuildPath(PARENT, u) Backtracking 
def BuildPath(PARENT, u):
    PATH = []
    while u is not None:
        PATH.append(u)
        u = PARENT[u]
    PATH.reverse()
    return PATH
  • Creates an empty list called PATH starting from goal node.
  • Uses PARENT dictionary to trace backwards to start node.
  • Adds each node and reverses the list for correct forward route.

Slide 8 — Execution Cycle

How UCS Works in Each Iteration

1 Select Min Cost

Extracts & pops node with lowest cumulative cost from Frontier.

2 Check Goal

Checks if popped node is goal. If so, returns optimal path and cost.

3 Mark Explored

Adds node to Explored set so it is never re-processed.

4 Explore Neighbors

Examines outgoing edges to all unvisited neighboring nodes.

5 Calculate Costs

Computes cumulative cost from start to each neighbor via current node.

6 Update Costs

If neighbor is new or cheaper path found, updates its cost and parent.

7 Update Frontier

Adds new nodes or updates existing nodes in priority queue.

8 Repeat Process

Continues until goal is popped or Frontier becomes completely empty.
